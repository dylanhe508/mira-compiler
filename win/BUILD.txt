Mira build command (Windows / MinGW GCC)

Run from the source root:

gcc -O2 main.c lexer.c parser.c codegen.c hash.c memory.c error.c codegen\decision.c codegen\ir.c codegen\ir_opt.c codegen\ir_cfg_cleanup.c codegen\ir_dump.c codegen\encoder.c codegen\coff_writer.c codegen\elf_writer.c codegen\abi_win64.c codegen\ssa_builder.c codegen\ssa_function_index.c codegen\ssa_lower.c codegen\ssa_dom.c codegen\ssa_opt.c codegen\ssa_affine.c codegen\ssa_module_facts.c codegen\ssa_vm_profile.c codegen\ssa_ref.c codegen\ssa_ref_vm.c codegen\ssa_mem2reg.c codegen\ssa_regalloc.c codegen\target.c linker\coff.c linker\dll_map.c linker\linker.c linker\pe.c linker\elf.c linker\elfout.c linker\symbols.c -ldbghelp -o mira.exe

For a debuggable compiler build, replace `-O2` with `-O0 -g` and write the
output to `mira-debug.exe` so the release compiler is not overwritten.

Requirements:
- Windows x86-64
- MinGW-w64 GCC

Recommended complete build (compiler and runtime objects):

    mingw32-make

The runtime build disables MinGW's private printf wrappers so generated PE
files only reference symbols supported by Mira's built-in linker.
