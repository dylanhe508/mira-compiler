# Mira SSA 归纳变量强度削弱设计

## 目标

在 `-O3` 下把自然循环中可证明的整数表达式 `i * K + C` 转换为循环
携带的派生归纳变量：循环前计算一次初值，循环每次迭代只执行
`derived += step * K`。该优化必须通用，不识别函数名、测试名或具体常量。

## 范围

第一版只接受以下全部条件：

- 64 位整数 SSA 运算；
- 单回边自然循环，循环头支配循环体和回边；
- 已识别出唯一的基础归纳变量槽，更新形式为 `i = i + step`；
- `step`、`K` 和可选偏移 `C` 都是编译期常量；
- 候选表达式位于循环内，基础归纳变量在候选表达式之前没有额外写入；
- 候选结果不参与控制基础归纳变量自身的更新；
- 智策的 `allow_affine_recurrence` 允许该循环执行优化。

第一版不处理多回边循环、可变步长、浮点数、指针算术、除法、跨函数状态、
异常溢出语义或需要运行时检查的情况。

## 变换

源循环：

```text
i = initial
loop:
    value = i * K + C
    use(value)
    i = i + step
```

转换为：

```text
i = initial
derived = initial * K + C
loop:
    value = derived
    use(value)
    i = i + step
    derived = derived + step * K
```

Mira 整数机器运算采用 64 位二进制回绕；初值和增量均使用相同的 64 位
运算，因此转换保持溢出结果一致。若现有 IR 对有符号溢出另有可观察行为，
优化必须拒绝候选。

## 实现位置

- 在 `codegen/ssa_opt.c` 增加独立的
  `ssa_opt_induction_strength_reduce(SsaFunction *)`。
- 复用 `ssa_analyze_loops` 产生的自然循环成员、回边、归纳槽和步长信息。
- 在常量传播、变量转发和首次 DCE 收敛后运行，使候选表达式已经规范化；
  在 LICM 和最终 DCE 前完成重写。
- 在 `codegen/ir_ssa.h` 暴露优化入口，方便小型 C 级单元测试直接构造 SSA。
- 不修改现有机器级 `ir_opt_coalesce_affine_recurrences`；它处理的是另一种
  `state = state*K+C` 模式。

## 安全证明

优化器为每个候选检查：

1. 循环只有一个入口和一个回边。
2. 初始化块是循环头的唯一非循环前驱。
3. 基础归纳变量只有规范更新，没有循环内其他写入。
4. `i*K+C` 的使用全部被新的派生值支配。
5. 派生值更新被插入所有回边之前，并且不会越过调用、内存写或所有权操作。
6. 新增 VReg 保持单一定义；若无法建立合法 PHI/循环携带关系，拒绝优化。

任何证明失败都保持原 SSA 不变。

## 智策与编译时间

该 pass 只在 `-O3` 且 `allow_affine_recurrence` 为真时执行。每个函数建立一次
VReg 定义/使用索引，并对每个循环线性扫描成员指令；总预算为
`O(函数指令数 + 循环成员数)`，不做组合搜索。目标是不让十行程序预热后三次
编译中位数超过 100 ms。

## 测试与验收

- 新增正步长、负步长、非 1 步长、负常量、带偏移和 64 位回绕回归。
- 新增拒绝测试：变量步长、多回边或归纳变量被额外写入时不变换。
- `-O0` 至 `-O3` 输出必须与 GCC/C 预言机一致。
- 六个极端应用与已有 SSA、ABI、除法回归必须全部通过。
- 长矩阵结果必须继续等于 `-7778248811425506175`。
- 反汇编中热点内层循环的 `c * 19349663` 不再每次执行乘法。
- 长矩阵 Mira `-O3` 中位数必须低于当前基线 `64.3 ms`；若未提升则保留
  正确性代码但默认关闭该策略，并记录原因。
