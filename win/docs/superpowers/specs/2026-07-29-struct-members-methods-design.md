# Mira 结构体成员与方法语法设计

## 目标

在不改变现有 SSA、寄存器分配和 x64 后端的前提下，为现代语法增加：

- `value.field` 字段读取；
- `value.field = expression` 及复合赋值；
- `impl Type { ... }` 方法定义；
- `value.method(args...)` 静态方法调用；
- `self` 与 `mut self` 可变性检查。

现有 `Type.field(value)` 形式继续兼容。

## 语义

```mira
struct Point {
    x: i64,
    y: i64
}

impl Point {
    fn sum(self) -> i64 {
        self.x + self.y
    }

    fn move_x(mut self, delta: i64) {
        self.x += delta;
    }
}
```

- `let` 绑定的结构体不可修改字段，也不能调用 `mut self` 方法。
- `mut` 绑定的结构体可修改字段并调用 `mut self` 方法。
- 普通 `self` 只读，`mut self` 可修改原实例。
- 第一版不支持继承、虚函数、动态分派、方法重载和泛型方法。

## 实现架构

采用前端静态展开：

- 解析器为局部绑定记录结构体类型和可变性。
- `impl Point` 内的方法注册为带类型命名空间的普通定义，内部符号使用不会与源码标识符冲突的稳定名称。
- `point.sum()` 在前端解析为对 `Point` 方法的直接调用，并把 `point` 作为第一个参数。
- `point.x` 解析为现有结构体字段访问，继续使用 `StructDef` 的字段偏移。
- `mut self` 通过原实例引用工作，不复制实例。
- SSA 只接收已有的调用、加载和存储节点，不新增成员专用 IR。

## 名称解析与错误

编译期拒绝：

- 未知字段或未知方法；
- 接收者类型无法确定；
- 对 `let` 实例写字段；
- 用只读实例调用 `mut self` 方法；
- 同一结构体内重复的方法名；
- `impl` 指向不存在的结构体；
- 在 `impl` 外使用 `self`。

诊断必须包含结构体名、成员名和源码位置。

## 验证

- 正例覆盖字段读取、字段写入、复合赋值、只读方法、可变方法、多参数方法及新旧语法混用。
- 负例覆盖全部名称解析和可变性错误。
- 新增用例在 `-O0` 至 `-O3` 下输出一致。
- 解释执行与本机编译结果一致。
- 现有 modern、结构体、SSA、寄存器与性能回归不得退化。
- 10 行级程序预热后三次编译中位数保持低于 100 ms。
