# Mira 极端应用测试套件设计

## 目标

用可重复、可限时、可由 C 结果对照的完整程序组合，暴露 Mira 在 O0–O3 下的跨函数、循环状态、整数溢出、分支、除法、寄存器压力和内存生命周期错误。

## 结构

每个场景由一个独立 `.mira` 程序和 `oracle.c` 中的同名实现组成。统一 PowerShell 驱动负责构建 C oracle、用当前 Mira 编译 O0–O3、链接运行、施加超时并比较逐行输出。性能测试只在 O3 正确后进行，采用三次预热和十一轮交替运行的中位数。

## 第一批场景

- `telemetry_pipeline`：多阶段数据清洗、分类、窗口累计与多函数调用。
- `particle_simulation`：多状态整数粒子模拟、边界反弹和能量校验。
- `hash_aggregation`：64 位溢出、桶聚合、多累加器和不可预测分支。
- `matrix_stencil`：二维邻域计算、嵌套循环、索引算术和双阶段归约。
- `allocator_churn`：多块堆内存、交叉读写、重叠移动与释放。
- `deep_control_flow`：深调用链、冷热分支、除法、取模和高寄存器压力。

## 验收

- 每个场景 O0、O1、O2、O3 的输出与 C oracle 完全一致。
- 编译、链接、运行均有 10 秒硬超时。
- O3 性能报告包含 Mira/GCC 中位运行时间、比值、编译时间和文件大小。
- 任何失败立即停止并保留场景、优化等级、输出和退出码，不修改优化器。
