# 静态引用驱动的核心全局图着色设计

## 目标

在已有 12 色 Win64 分配和 ABI 保存恢复之上，为高压力 SSA 函数增加有界全局图着色，
减少线性扫描因局部到达顺序产生的 spill，同时保持编译时长和合法性可预测。

## 职责分层

- SSA 活跃区间提供干涉关系，决定哪些值不能共享颜色。
- 静态引用提供值已知比例、未知副作用和规模预算，决定证据是否足以启用全局着色。
- 循环深度与使用次数提供节点优先级，决定热点值先着色。
- 智策输出 `prefer_global_graph_coloring`，控制是否执行及干净回退。

静态引用不替代干涉图；它负责证明和决策，干涉图负责寄存器合法性。

## 核心算法

候选节点为活跃的整数 SSA interval。按现有 priority
`use_count * (1 + loop_depth * 10)` 降序排列；priority 相同则优先短区间和较小 VReg，
保证确定性。

对当前节点，检查所有已着色且活跃区间相交的节点，将其颜色标为不可用；同时合并：

- fIR 已预占颜色；
- 跨调用值禁用颜色 0–4；
- 跨 SDIV/SREM 值禁用颜色 0 和 2。

选择最小合法颜色；无颜色则 spill。节点数超过 512、分配失败或智策关闭时，完整回退
到当前线性扫描。图着色不会修改 SSA、CFG、变量槽映射或 lowering。

## 智策与静态引用门控

仅 O3 考虑启用。必须满足：

- 活跃整数节点为 8–512；
- 估计标量压力至少 8；
- 静态引用 `value_count` 不超过 4096；
- 不存在静态引用未知副作用，或已知值比例至少 50%；
- 预计 spill/高压力收益高于函数保存成本。

第一阶段不接变量槽竞拍、全局变量基址、循环槽保护或图重写。

## 验证

- 结构测试覆盖干涉/不干涉、跨调用、跨除法、fIR 预占、确定性和 >512 降级。
- 决策测试覆盖 O0–O2 关闭、低压力关闭、静态引用证据不足关闭和 O3 高压力开启。
- 语义回归复用 PHI、divrem、非易失调用、极端应用。
- 形状测试比较线性扫描与图着色 spill 数，要求不增加。
- 长矩阵同环境交错基准不得回退超过 5%；预热编译中位数低于 100 ms。
